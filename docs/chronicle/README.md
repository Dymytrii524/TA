# Хроніка Trans-Atlas

Інтерактивна карта шляху розробки: фази, що реалізовано, що працює частково, що залишилось. Ведеться як Claude-артефакт, який оновлювався на місці, тож один і той самий URL з часом показує дедалі новіший стан.

## Що змінилось між проміжною і кінцевою версіями

Шість вузлів, які були «специфікацією» (сині), виконано:

- **Працюють:** сторінка SEARCH (рушій і ворота POST_DRONE), сторінка верифікації (живі VIES, Biała lista, KRS), сторінка check-call (структурна перевірка діаграм).
- **Частково:** бекенд Спринт 0 (лише читальний `/api/v1`), рішення про стек, план Спринту 1.

Додано статус «частково», фазу «Спека → код» і три нові пункти «залишилось»: ключі для санкцій і ЄДР, суперечність критерію Спринту 1 №2 з каталогом перевірок, тести нових модулів поза правилом гілки. Пункт «D12 червоний на main» прибрано: це був артефакт CRLF у робочому дереві Windows, а не розбіжність файлів.

## Обмеження

- **Найпершу версію артефакту відновити неможливо:** її замінили на місці, локально не збереглась. «Початкова» тут означає найранішу з тих, що збереглись.
- Артефакти **приватні**: посилання відкриються лише власнику й тим, кому він надав доступ через меню «Поділитись». Знімки `.html` у цій папці — повні копії сторінок, їх можна відкрити локально в браузері без доступу до claude.ai.
